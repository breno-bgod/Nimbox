# Nimbox Design System

**Versão:** 1.0.0 · **Fase 01: Fundação Visual** · **Escopo: design-only**

Nesta fase, a fonte visual é o **Preview Premium 3.0**, com o Preview 3.1 como versão sem controles fictícios. As definições visuais são uma proposta oficial para revisão e validação antes de modificar o renderizador C++ ou os fluxos reais do Nimbox.

## Arquivos

- [Guia completo](v1.0.0/README.md): identidade, cores, materiais, iluminação, tipografia, componentes, animações, som, navegação e critérios de aceite.
- [Tokens de design](v1.0.0/tokens.json): dados estruturados exportáveis para ferramentas e implementação posterior.
- [Galeria visual offline](v1.0.0/gallery.html): abra em um navegador para experimentar os temas, foco, movimento e protótipos de áudio.

## Regras

- Nenhum motor gráfico, código de autenticação, catálogo, streaming, input ou configuração operacional é alterado nesta fase.
- O HTML é **referência/galeria**, e não a interface funcional do aplicativo.
- O design não será considerado implementado sem comparação lado a lado com capturas reais da plataforma.
- Valores que não vêm diretamente da referência 3.0 são propostas para aprovação visual.
